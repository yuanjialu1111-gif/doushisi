# 斗十四大厅 · 本机演示

本机（Mac）演示网页版和后台。账号密码都存在 `.local/` 目录里（不进 git），本文件不写密码。

## 启动

```bash
cd /Users/mac/Documents/Projects/斗十四 && pnpm build && pnpm --filter @dss/server start
```

在 Claude Code 里也可以用 `.claude/launch.json` 里的 `doushisi-server` 启动。启动后的地址：

| 端 | 地址 |
|---|---|
| 网页版游戏 | http://localhost:3000/client/ |
| 后台 | http://localhost:3000/admin/ |

改了 `apps/server` 要先重新构建再重启（启动的是 `dist/main.js`）。只改了 `client/public/standalone.js` 的话，刷新网页就能生效。

## 走查路线（约 10 分钟）

1. **首次资料（R6）**：用一个还没设资料的号登录 → 弹出资料面板，关不掉 → 上传头像、填昵称、选性别 → 进入大厅。
2. **大厅（R1、R4）**：首页点「好友约局」打开大厅，看到系统常驻桌。左栏切换玩法筛选；点「快速开始」会直接入座。
3. **门槛（R5）**：拿一个豆子少于「底分 × 10」的号点桌子 → 提示还差多少豆子。
4. **公开开房（R3）**：大厅底部点「创建房间」→ 勾「公开到大厅」→ 房费自动切到 AA 并提示。开好以后，另一个号在大厅里能看到这一桌。
5. **附近（R10）**：浏览器允许定位以后，大厅出现「附近」页签，只列有人的桌子，只显示「1 公里内」这类档位。不给定位就没有这个页签，其他照常。
6. **牌桌（R7、R11）**：入座以后，每个人显示自己的头像；没有定位按钮，也没有距离。
7. **改资料（R8）**：首页点头像 → 个人信息里点「换头像」「改昵称」。昵称 30 天只能改一次。
8. **后台（R2、R9）**：豆子管理员登录 →「大厅桌模板」可以改常驻空桌数、门槛倍数和清座时限；「头像审核」可以驳回头像或昵称。
