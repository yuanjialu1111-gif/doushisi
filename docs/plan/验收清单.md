## 只能在真机或装好工具后验证

由你来做。命令见 `.planning/2026-10-30-lobby/progress-android.md`。

1. 装工具，生成签名钥匙，打包：apktool 解包和回包、apksigner 签名并校验。
2. 选图：相册、拍照、拒绝权限、中途取消。
3. 定位：第一次会弹授权框。拒绝后大厅照常能用，只是没有「附近」页签。
4. 热更新：断网启动时用 APK 内置版；服务器发了新版后，下次启动能拿到。
5. 测试机要先卸载旧版，因为签名换成了你自己的钥匙。
