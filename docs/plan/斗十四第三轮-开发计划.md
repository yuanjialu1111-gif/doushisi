# 斗十四第三轮开发计划

依据：`docs/requirements/斗十四第三轮-需求简报.md`（全部已定）、DEC-20261031-第三轮规则v2、DEC-20261031-第三轮剩余待拍板与去勋章。用户授权做完自测后自己发布测试服 108 并打包，最后只给下载地址。

## 做法总览

| 里程碑 | 内容 | 主要文件 |
| --- | --- | --- |
| M1 规则 v2 | 门槛按人数、豁免；只一家胡（逆时针，翻牌从翻牌人起）；点炮包三家；跟头翻 5 番封顶；鬼/碰/杠/全红/全黑/天走/接地番；巴杠；规则版本记在桌规则 `xinjin.scoring='v2'`，老桌 v1 打完 | `packages/rules/src/edition.ts`、`apps/server/src/game/xinjin-win.ts`、`xinjin-round.ts`、`docs/rules/XINJIN-INDEPENDENT.md` |
| M2 牌桌画面 | 胡牌后发原版小结算 `smallResult`（手牌、胡的那张、摆出的牌、鬼、番型、红黑点、番数、昵称），原版自带胡牌特效（红胡、黑胡、天胡、地胡）和 1.5 秒延时；最后一局后再看总结算；E3 红黑点、E4 偷、E6 报叫走原版已有消息 | `apps/server/src/game/round-original.ts`、`rooms.ts`（昵称） |
| M3 托管 | 托管打牌优先打不成对、红点少的牌 | `xinjin-round.ts` `xinjinTimedAction` |
| M4 大厅改版 | 好友、私聊、邀请、开房入口和接口下线（表不删）；点空位直接坐那个位；系统桌一场打完自动开下一场新桌（同座位、场次 +1、每场扣 AA），15 秒内不点继续算离开 | `rooms.ts`、`lobby.ts`、`app.ts`、`client/public/standalone.js`、迁移 014 |
| M5 去勋章 | 资料页勋章块、`/api/players/:uid/medals`、stats 点亮逻辑去掉，account_medals 不再读写 | `stats.ts`、`app.ts`、`standalone.js`、后台 |
| M6 自测发布 | 全量测试、typecheck、build、接入层测试、安卓自测；本机提交；发布 108；下载页 APK 照旧（接入层走热更新），必要时重打包 | `tools/release-test-server.sh` |

## 自己定的实现细节

- 规则版本：不改引擎版本号（`xinjin-independent-v1` 留作快照兼容），在冻结规则里加 `xinjin.scoring: 'v2'`；没有这个字段的老桌按 v1 结算。
- 2 人桌门槛按 25。
- 连着打：每场是一张新桌记录（`rooms` 每桌只能扣一次房费，表结构不动），新桌记 `match_seq`（第几场）和 `previous_room_id`，迁移 014 只加列。
- 底分本轮不改。
