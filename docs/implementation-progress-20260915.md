## 已完成的代码

- `apps/server/src/game/cards.ts`：实体牌唯一编号、重复牌区分、显式牌堆、原子移动和发牌、牌张守恒检查、按玩家过滤隐藏牌。没有默认假设52张底牌或庄闲发牌数。
- `apps/server/src/game/combinations.ts`：对地区模块提供的合法组合进行精确覆盖搜索，区分实体牌并枚举多种分解。搜索超限明确报错，不截断后误判最佳胡牌。此模块本身不规定何种组合合法。
- `apps/server/src/game/claims.ts`：收集同一响应窗口内的选择，按地区传入的优先级、并行许可及座次顺序裁决；支持过牌、重复响应和过期窗口检查，不向其他玩家展示候选手牌。
- `RoundInput` 增加 `ownerUserId`、可选 `previousRoundContext`；`EngineResult` 增加可选 `nextRoundContext`。
- 迁移009增加 `rounds.next_round_context`。上下文只随最终结算提交，失败一起回滚；已结算记录禁止修改。旧数据保持空值，不猜补庄家。
- 房间服务从上一局已保存的上下文开始下一局；回放核对上下文和原始动作是否一致。玩家视图不包含私有上下文。
- 本地验收检查必须覆盖每种人数和每种4/8/12局配置，并匹配当前地区引擎版本；只验证4局或旧引擎版本不能通过。
- 构建指纹现在包含验收器代码，修改验收规则后需重新构建。
- 新增原包规则静态解析器，使用AST读取常量，不执行APK脚本，并逐地区核对当前配置与原始代码是否一致。
