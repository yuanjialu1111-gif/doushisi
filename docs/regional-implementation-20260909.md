## 邛崃实现边界

版本`qionglai-additions-v1`携带三个0/1开关，创建后冻结。原协议V2的`createRoom.qionglai`与`roomOptions.qionglai`覆盖开房、入桌、登录恢复和回放快照。其他地区不能注入这些字段，能力不符的旧客户端拒绝新邛崃入桌。未修改旧房间规则。

`apps/server/src/qionglai-patterns.ts`仅实现已确认条件：原始庄家起手、闲家胡庄家首次普通弃牌、剔除奖励牌/王后的普通牌全红或全黑、基础合法胡之后红点或黑点≥50。真实胡牌与点数必须由未来服务端引擎提供，不能接收玩家自行申报。牌型叠加再封顶的函数要求完整已批准番数表；缺少开关、批准依据或任一番数均拒绝。六项番数冻结为null，未注册成可玩引擎。

基础胡牌、实体牌堆、王和白板、偷补、付款关系仍待规则审定。需要确认的六项番数及原包证据见[邛崃审定表](rules/QIONGLAI-REVIEW.md)。
