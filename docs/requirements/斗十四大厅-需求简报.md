# 需求简报：斗十四大厅公开桌 + 首次上传头像 + 附近桌子

状态：用户已确认（2026-10-30）
方案图：https://claude.ai/artifact/TF467m5uNcJYC55RvjwQNe （分层架构、核心流程、界面示意、必做项）

## 目标、用户与使用环境

- **要解决的问题**：
  - 现在要自己开房，或者输入 6 位房号才能玩。
  - 所有人头像都一样，分不清谁是谁。
  - 定位有毛病。
- **使用者**：
  - 玩家，主要用安卓 APP，网页版 `/client/` 用来先验收。
  - 运营，用后台 `/admin/`，只能通过 SSH 隧道进入。
- **成功的样子**：
  - 打开 APP 就能看到所有可坐的桌子，点一下就坐。
  - 每个人都有自己的真实头像和昵称。
  - 大厅能挑附近的桌子，进了桌子里看不到别人离自己多远。

## 第一版范围

- **必做**：R1–R11。
- **暂不做**：
  - 按 GPS 自动选大厅地区（二期）。
  - 第三方图片自动审核。
  - 同 IP 提醒、距离过近提醒。
  - 国内不开代理直连的问题，见待决定项。
  - iOS。
  - 预设头像。
- **上线方式**：
  1. 先在本机网页版做完，你验收。
  2. 再打安卓包（换新签名，测试机卸载旧版一次）。
  3. 最后部署到测试服，发布脚本由你点运行。

## 核心流程与规则

1. **注册或登录**：服务端发现资料没设，就弹出资料设置，不能跳过，老账号也一样。
2. **资料设置**：
   - 头像只能拍照或从相册选，不提供预设头像。
   - 昵称 2–7 个字，不能重名。
   - 选性别，性别决定快捷语音用男声还是女声。
   - 设好后才能进大厅。
3. **大厅**：
   - 按玩法筛选，分「全部」和「附近」两栏。
   - 点桌子入座，或点「快速开始」。
   - 自己开房、输房号照常保留。
4. **系统桌**：
   - 后台按模板常驻空桌。
   - 有人离开只空出座位，坐满且都准备后开局，统一 AA 扣房费。
   - 打完设定局数，桌子清空回到空桌。
   - 坐着太久不开局，自动清座。
5. **玩家桌**：开房时勾选「公开到大厅」就会出现在大厅，不勾只能输房号进。
6. **牌桌**：没有定位按钮，不显示距离，不会因为定位被拒。

## 需求与验收

### R1 大厅桌子列表

用桌子网格替换原来的「好友约局」入口。每张桌子显示玩法、底分、局数、几缺几，以及已坐玩家的头像。

- AC1：A 在大厅时，B 坐进一张桌子，A 不刷新就能在 3 秒内看到这张桌子的人数和 B 的头像变化。
- AC2：按玩法筛选后，只显示这个玩法的桌子。没有桌子时显示空状态，不出错。
- AC3：没勾「公开到大厅」的玩家房，任何人在大厅里都看不到。

### R2 系统常驻桌

后台为每个玩法配置桌模板：底分、人数、局数、常驻空桌数、入座门槛倍数。

- AC1：模板设为常驻 3 张空桌，其中 1 张坐满开局后，大厅在 3 秒内补出 1 张新空桌。
- AC2：开局前有人离开，桌子还在，只空出这个座位。原来「房主一走就关房」的规则对系统桌不生效。
- AC3：打完设定局数并结算后，桌子回到 0 人状态。
- AC4：有人坐下后超过清座时限（AI 暂定 10 分钟，后台可改）还没开局，自动清座并通知本人，不扣任何豆子。

### R3 玩家桌公开到大厅

开房面板加一项「公开到大厅」，默认不勾（AI 建议）。

- AC1：勾了的房间出现在大厅，别人点了能入座。规则照开房时的设置，和输房号进的效果完全一样。
- AC2：不勾的房间只能输房号进入。

### R4 快速开始

- AC1：点「快速开始」后，在当前玩法里找有空位、而且自己豆子够门槛的桌子，人最多的优先，直接入座。
- AC2：找不到合适的桌子时，按这个玩法的模板新开一张并入座。豆子哪一档都不够时，提示「豆子不足」，不入座。
- AC3：入座后，牌桌显示的底分和最终结算用的底分一致。

### R5 房费与门槛

- AC1：公开桌（系统桌和公开的玩家桌）一律 AA，第一局所有人准备后才扣房费，规则沿用现在的。
- AC2：豆子少于「底分 × 倍数」的人点桌子入座，会被拒绝并提示还差多少。倍数按模板配置，AI 暂定 10 倍，后台可改。

### R6 首次资料设置

- AC1：新注册的号第一次登录，必须先上传头像、填昵称、选性别，才能进大厅。设置界面不能关。
- AC2：老账号下次登录，同样先完成资料设置。
- AC3：昵称少于 2 个字或多于 7 个字、和别人重名、或含敏感词时，提示原因，不能保存。
- AC4：头像可以拍照，也可以从相册选。安卓和网页版都能完成。

### R7 头像显示到所有地方

- AC1：4 个号各设不同的头像后，在大厅桌子、牌桌、好友列表、个人信息、战绩回放和后台玩家列表里，每个人显示的都是自己的头像。
- AC2：A 换了头像后，B 不用重启 APP，重新进入大厅或牌桌就能看到新头像。

### R8 改头像和改昵称

在个人信息页加「换头像」和「改昵称」两个入口。

- AC1：换头像随时可以，规则和 R6、R9 相同。
- AC2：昵称 30 天内只能改一次。没到 30 天时，提示下次可改的日期。

### R9 照片处理与审核

- AC1：上传的照片由服务端重新压缩成 256px 以内，去掉拍摄位置等附带信息。下载回来检查，查不到原来的位置信息。
- AC2：照片上传后立即显示，后台可以驳回。被驳回的号头像变回默认灰色头像，下次登录要重新上传。驳回操作要留下记录。
- AC3：后台可以驳回昵称。被驳回后，这个号下次登录要重新填昵称。
- AC4：文件太大或不是图片时，提示原因，不影响原来的头像。

### R10 附近的桌子

- AC1：大厅有「附近」一栏，按桌上离你最近的已坐玩家来排序。只显示「1 公里内 / 5 公里内 / 同城 / 更远」这样的档位，不显示精确米数。
- AC2：空桌不进「附近」，只在「全部」里出现。
- AC3：不给定位权限的人，大厅照常能用，只是看不到「附近」这一栏，也不会被挡在门外。
- AC4：网页版的定位经纬度都正确。修掉原版代码里经度永远是 0 的问题。

### R11 房内不显示距离

- AC1：牌桌上没有定位按钮，任何时候都不弹出距离面板。
- AC2：开房面板里不再有「开启GPS定位」选项，进房和断线重连都不会因为定位被拒。
- AC3：以前开了 GPS 选项、现在还没解散的房间，同样不再要求定位。

### 安卓包配套（R6、R10、R11 依赖）

- **新签名**：用项目自己的签名钥匙，钥匙不放进源码。
- **选图和拍照**：新增拍照、从相册选图两项功能。
- **定位权限**：进大厅时申请定位权限，拒绝也照常能玩。
- **热更新**：APP 启动时从服务器拉取最新的接入层脚本，并校验哈希。以后改界面不用重装 APP。
- AC：测试机卸载旧版、装上新版之后，再发布界面改动，不需要重装 APP 就能生效。
