# 雅安红二十独立规则 v1

日期：2026-09-24。配置：仅`6:0`经典玩法。版本：`yaan-independent-v1`。

定稿依据：[用户全部自动批准](INDEPENDENT-APPROVAL.md)。原包明确数值继续优先；以下未由原包直接证明的内容是开发方独立定义，不宣称等同原服务器。原包已明确的报叫3番、金二十1番、暗四对3番、每龙3番及现有计分组件保持不变，见[原包计分组件](YAAN-IMPLEMENTATION.md)。

## 牌堆

普通牌由四种花色A至K各一张组成52张，7保持四个实体。按`qiWangNum`设置决定7是否作为癞子参与组合：

| 7当王 | 实体牌处理 |
| ---: | --- |
| 0 | 四张7均为普通牌 |
| 4 | 四张7均为癞子 |
| 6 | 四张7加一张红7、一张黑7为癞子，作为额外特殊实体 |
| 8 | 两副共八张7为癞子 |
| 12 | 三副共十二张7为癞子 |

王牌按原包3/6/9/12档，分别为小王、大王、白板等分；所有王牌均为癞子，不计红黑点，不能作为独立的普通牌面参与凑14计点。

## 判胡与红点

普通胡由四组组成：两张凑14、同点三张碰/偷、同点四张杠/巴；已落地组合按其真实张数占组数，余下暗手逐两张凑14。四张同点可组成一个暗四对中的龙，开启暗四对时計3番，每个龙另加3番。

红点：花色1、3为红，2、4为黑；A/J/Q/K各1点，2至10按牌面值。只计算最终胡牌结构中的真实普通牌，癞子本身不计点。普通胡门槛为红20点这一独立定义与邛崃相同，但雅安不套用邛崃天地胡、全红全黑或红50/黑50的番数。

## 独立补足项

- 报叫：服务端认定报叫成立后3番，且报叫后锁定听口，不能换听口。
- 金二十：恰好红20点1番；19/21不触发。
- 暗四对：3番；每个龙另加3番。
- 红50/黑50：至少50点，且必须已由服务端认定合法胡牌；本版各定3番。
- 杠上花/杠上炮：原开关保留，本版各定1番。
- 金钩钓：仅碰光、暗手一张时成立；本版定3番，与原包已明确的邛崃数值相同但作为雅安独立定稿记录。
- 金钩钓结构：胡牌前暗手一张、三组落地牌均为碰/杠/巴；胡牌张加入后必须与另一张暗手形成合法牌组。服务端不允许单张暗手直接通过。
- 天胡/地胡各3番；全红3番、全黑4番。无其它番的合法胡按0番结算，不套用邛崃可平胡3番。
- 流局查叫：开启时按与邛崃相同的中性单份规则结算；关闭时不追加输赢。
- 报叫后锁定服务端计算的听口；响应窗口仍可胡，但不得再吃、碰、杠或补巴改变手牌结构。
