# 安岳斗十四独立规则 v1

日期：2026-09-24。配置：仅`5:0`。版本：`anyue-independent-v1`。

定稿依据：[用户全部自动批准](INDEPENDENT-APPROVAL.md)。原包明确写出的选项与公式优先；未由原包证明的部分是开发方独立定义。

## 牌堆与结构

安岳原包**没有王数选项**，也没有7当王数量档位；只有布尔开关`qiToWang`。因此本版不能把其他地区的王数档位套给安岳。

独立定义：普通牌为四花色A至K各一张，共52张；另固定加入小王、大王、白板各1张，共55张实体牌。这个3张特殊牌的构成是开发方独立定稿，不是原包证据，也不能据其他地区王数档位推定。

7当王开启时，四张7为奖励牌，偷出后每张1番，不计红黑点；关闭时按普通7使用。三张王作为奖励牌偷出，每张1番，不计红黑点、不留在胡牌结构内。

普通结构为四组：两张凑14、同点三张碰/偷、同点四张杠/巴；余下暗手逐两张凑14。红点按花色1、3为红，2、4为黑；A/J/Q/K各1点，2至10按面值；只计算真实普通牌，癞子替代不计点。普通胡门槛为红20点。

## 打漂

| 模式 | 值 | 规则 |
| --- | ---: | --- |
| 不漂 | 0 | 每家漂值固定0 |
| 必漂 | 1 | 每家漂值固定1 |
| 选漂 | 2 | 开局30秒内各自选择0或1，超时记0 |

漂是付款公式的加项，不是独立番型。

## 番表与公式（独立定稿）

| 项目 | 番数 | 来源 |
| --- | ---: | --- |
| 奖励牌 | 每张1 | 独立定稿；偷出的三张王及开启的7，均不计红黑点 |
| 对子胡 | 3 | 独立定稿；完全未落地的四个同点对子 |
| 全红/全黑 | 3 | 原包提示“全红、全黑3番” |
| 打庄 | 1 | 独立定稿；赢家或付款人涉及庄家时加1 |
| 扯拢 | 1 | 独立定稿；胡牌时奖励区已有至少两张奖励牌 |
| 点炮包赔 | 不另计番 | 只改变付款人：出牌者代付其余有效玩家的份额 |

滚滚翻单份为`底分 × (1 + 赢家漂 + 付款人漂) × 2^封顶后番数`；颗颗加单份为`底分 × (1 + 赢家漂 + 付款人漂 + 封顶后番数)`。先汇总番数再按4/5/6/99封顶。

## 付款

- 自摸：其余玩家各付一份。
- 普通接炮：出牌者付一份。
- 点炮包赔开启：出牌者代其余有效玩家付款，即支付其余有效玩家应承担的全部份额。
- 流局不追加输赢；无牌可翻或无牌可补即流局。
