# 新津斗十四：首批独立定义审定

## XJ-D03-1 实体牌堆

原包确认四花色A至K的52种牌面资源；新津开房提示直接给出3王=小/大/白各1，5王=2/2/1，6王=2/2/2，9王=3/3/3。原包没有给普通实体牌的重复数。

待确认独立定义：四花色A至K各一张，共52张普通牌；王按原提示添加。因此3/5/6/9王分别为55/57/58/61张实体牌。7当王只改变四张普通7的玩法角色，不增加或删除实体牌。

成立例：3王时有四张普通7、一个小王、一个大王和一个白板，总55张。不开“7当王”时四张7仍是普通牌。

不成立例：选择6王后把所有普通牌翻倍为104张；这种解释属于另一牌堆，不在本独立定义中。

本项没有付款、胡牌或豆子结算；仅确定实体牌清单。记录精确批准时引用“XJ-D03-1、配置4:0、上述四种王数与7当王不改数量”，不能使用“按计划做”代替。

## XJ-D04-1 基础完成组合

原客户端吃牌选择一个服务器候选中的手牌；外部2017扑克规则和2020沿河文章均支持两张凑14，但不能据此确定新津全部合法动作。

待确认独立定义：普通完成结构恰为四组，每组为两张普通牌点数合计14，或按规则已落地的同点三张碰、同点四张杠。A至K组合值为1至13。未落地的同点两张不作普通组，7+7除外；暗四对、龙对等特殊胡另行定义。王的偷、听用与补牌也必须另行审定，不能从此条推断。

成立结构例：红桃5+方块9、梅花A+黑桃K、红桃2+方块Q、梅花6+黑桃8，四组凑14；这仅证明组合满足条件，尚须检查起胡红点和机会来源。

不成立结构例：以红桃5+方块5替换第一组，且不开任何特殊对子胡；这组不满足普通凑14。

本项未决定能否接炮、付款家数和番型，不能给未定稿的金额造预期值。补齐XJ-D05、响应和支付规则后才产生完整判胡案例。

## XJ-D05-1 红黑点

原包下发redPoint/blackPoint；外部2017文本给红A/J/Q/K各1、2至10按面值，尚未证明本APK王/白板的替代计点。

待确认独立定义：红桃、方块计红点，黑桃、梅花计黑点；A/J/Q/K各1、2至10按面值。计完成牌中真实普通牌的点数，偷出的奖励牌不计。王和白板自身红黑点为0，若其他规则允许替牌，替牌不凭空增加红黑点；7当王被偷后也不再算7红或黑点。

成立例：红桃10+方块10为20红点；红桃J+方块Q为2红点；红桃10+白板仅有10红点。

不成立例：红桃10+白板因白板“代红10”自动算20红点；与本独立定义不符。

是否达到20红即可胡、恰20番数与其他牌型如何叠加，以及付款关系仍为后续条目，不能由上述点数表默认解锁。
