# 蒲江斗十四独立规则 v1

日期：2026-09-24。配置：仅`7:0`。版本：`pujiang-independent-v1`。

定稿依据：[用户全部自动批准](INDEPENDENT-APPROVAL.md)。原包明确写出的选项与番数优先；未由原包证明的部分是开发方独立定义。

## 牌堆

普通牌为四花色A至K各一张，共52张。王按原包6/9/12/15档，小王、大王、白板等分：6王各2张、9王各3张、12王各4张、15王各5张。蒲江没有7当王选项，四个7始终是普通7。

## 判胡与红点

普通结构为四组：两张凑14、同点三张碰/偷、同点四张杠/巴；余下暗手逐两张凑14。红点按花色1、3为红，2、4为黑；A/J/Q/K各1点，2至10按面值；只计算真实普通牌，已偷出的王不计点也不留在结构内。门槛为红20点。
