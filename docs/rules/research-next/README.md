### 2020 年沿河勾鱼介绍

已直接读取 [搜狐《斗十四规则技巧，学会秒变高手》](https://www.sohu.com/a/426564220_120894070)，作者为“大众游戏精选”，日期 2020-10-22，介绍“飞扬斗地主”小程序里的沿河勾鱼。

这份外部文章同样明确两张凑 14、庄 8 闲 7、公开翻牌不能直接上手；还写出七个 7 的组成是 4 张普通 7、大小王和花牌。其红点按十位四舍五入、特殊胡取最大值而牌 10 加分可叠加，报叫失败向赢家补足至少 50 的规则，均有具体文字可核对。

**已找到一个明确冲突：文章把七个 7 记为 100 分，原 APK 编号 2 一副牌的问号提示写 50 分。** 因此不能整套复制这篇文章，也不能据它把 D03 的完整 55 张牌堆直接宣布为原版已证实。它未枚举所有普通实体牌和白皮数量。

## 原包帮助资源复核

本次额外解析 Cocos 资源配置到实际 UUID，并查看 `gy_help1`、`gy_help2`、`helpother` 三张图片：均为提示底图，无可读完整规则。

`HallHelpUIController.loadGameConfig` 只把选中游戏名称写入标签；桌内规则按钮转入 `CommonPlayUI`，由它拼接当前开房选项。它们没有遗漏的全文牌堆、胡牌或红黑点规则说明。此结论只针对上述三图和两个已检查控制器，不代表所有图像均经过 OCR。

## 接下来应如何使用这些证据

1. 继续保留 D03、D04、D05 未批准状态；撤销任何准备直接采用“三张吃”或“普通任意对子完成组合”的实现假设。
2. 用两张吃、碰补一张和杠补两张这组外部案例，逐项核对原 APK 的摆牌数量、手牌回补、听牌、红黑点消息；若只验证 UI 消费消息，报告中仍须明确只是客户端行为。
3. 地区规则分别比对。尤其要继续找原产品的牌堆、癞子计点、血战和杠巴约束，不能把网上“四人四鬼”规则批量套给全部编号。
4. 当需要用户定稿时，应给出“原包证据、外部文字、两者冲突、剩余选择”的具体条目；当前没有提出新的默认批准。
