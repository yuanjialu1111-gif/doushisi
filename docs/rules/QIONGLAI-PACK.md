# 邛崃实体牌堆：已确认

条款：QL-D03-1。配置：仅8:0。版本：`qionglai-approved-pack-v1`。

## 确认依据

2026-09-16，本任务明确询问“普通牌四花色A至K各一张，共52张，再加所选王数。例如3王共55张，18王共70张”，并限定“仅适用于邛崃，不自动批准其他地区或其余未定规则”。用户回复：**“那就确认”**。

本条是用户批准的独立版定义，不宣称已经由原服务器完整发牌实测证实。原包对各档小王、大王、白板的组成有明确文字，见 `main/FrameGameConfig.js` 的8:0王数配置。此前准备拒绝回包的52张数值仍保留为历史观测，不作为本定义的总数。

## 实现与历史

- `apps/server/src/game/qionglai-pack.ts` 生成完整牌堆，复用已有实体牌管理。
- 新建邛崃房间在 `rules.qionglai.packVersion` 和 `packSource` 保存本条版本与确认来源，`rules.wangNum` 继续由原开房选项校验。
- 构造入口只接受8:0和已明确冻结的本版本。缺失版本的历史房间、未知版本、非邛崃配置及非法王数不会回退到新定义。
- 实现不洗牌、不替用户选择庄家，不假定发牌张数，不决定王的用途或分数。以后真实引擎创建快照时必须使用房间已冻结的版本。
- 本次不迁移正式数据库，不修改历史房间，不注册不完整地区引擎或开放收费开局。

独立预期清单：[六档牌堆算例](cases/qionglai-pack-v1.json)。测试核对52种普通牌、三种特殊牌数量、总牌数、实体ID、非法输入、跨地区拒绝、版本拒绝、序列化恢复、守恒和隐藏牌投影；房间测试使用隔离数据库检查六档持久化及历史不补写。普通移动测试是组件守恒案例，不代表偷补或发牌规则已经确认。

后续用户“全部自动批准”已授权开发方补全其余规则，不再等待逐项批准，见[授权记录](INDEPENDENT-APPROVAL.md)。本条牌堆版本保持不变；王用途、判胡、红黑点及付款的新定义见[邛崃独立规则](QIONGLAI-INDEPENDENT.md)，完整对局仍须实现和验收。
